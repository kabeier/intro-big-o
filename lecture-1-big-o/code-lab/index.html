1 · Count the steps: O(1) and O(n)

New file: growth.py. Type each block yourself (copy only if you fall behind), leave a blank line between blocks, save, then run.

Step 1 · growth.py

def get_first(items):
    return items[0]

Step 2 · growth.py

def linear_search(items, target):
    steps = 0
    for item in items:
        steps += 1
        if item == target:
            return steps
    return steps

Step 3 · growth.py

for n in [10, 100, 1000]:
    items = list(range(n))
    print(n, linear_search(items, n))

2 · A loop inside a loop: O(n²)

New file: pairs.py. Type each block yourself (copy only if you fall behind), leave a blank line between blocks, save, then run.

Step 1 · pairs.py

def count_pairs(items):
    steps = 0
    for a in items:
        for b in items:
            steps += 1
    return steps

Step 2 · pairs.py

for n in [10, 100, 1000]:
    items = list(range(n))
    print(n, count_pairs(items))

3 · Cut it in half every time: O(log n)

New file: halving.py. Type each block yourself (copy only if you fall behind), leave a blank line between blocks, save, then run.

Step 1 · halving.py

def binary_search(items, target):
    steps = 0
    left, right = 0, len(items) - 1
    while left <= right:
        steps += 1
        mid = (left + right) // 2
        if items[mid] == target:
            return steps
        elif target < items[mid]:
            right = mid - 1
        else:
            left = mid + 1
    return steps

Step 2 · halving.py

for n in [10, 100, 1000, 1000000]:
    items = list(range(n))
    print(n, binary_search(items, n))

Run it:

python3 halving.py
10 4
100 7
1000 10
1000000 20

4 · Branching: O(2ⁿ), and every ordering: O(n!)

New file: branching.py. Type each block yourself (copy only if you fall behind), leave a blank line between blocks, save, then run.

Step 1 · branching.py

import math

calls = 0


def fib(n):
    global calls
    calls += 1
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

Step 2 · branching.py

for n in [10, 20, 25]:
    calls = 0
    fib(n)
    print(n, calls)

Step 3 · branching.py

for n in [3, 5, 10]:
    print(n, math.factorial(n))

Run it:

python3 branching.py

20 21891
25 242785
3 6
5 120
10 3628800
