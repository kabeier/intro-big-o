What to notice

  • n = 10: everything looks fine. Even O(n!) is only 3,628,800 operations, which a laptop does in under a second.
  • n = 1,000: O(n) is 1,000, O(n²) is 1,000,000, and O(2ⁿ) is a number with 302 digits.
  • n = 1,000,000: O(log n) is still about 20. That is binary search: 20 looks to find anything in a million sorted items.
  • Big-O is about the shape of the curve, not the seconds. A faster computer moves every curve a little; it never turns O(n²) into O(n).
